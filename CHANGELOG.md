# Release notes

## 0.22.0

- Adds the `reproduce` command for sequential fresh-process experiments, complete raw outputs, source commitments, run-level statistics and a completion manifest.
- Adds a signed-evidence-to-review worked example with one-time execution, replay rejection and signature-tampering rejection.
- Records guest-visible hardware and resource limits, and adds an explicit environment-version check with pinned optional figure/build requirements.
- Provides command-line and Python interface documentation and a current ten-run numerical snapshot.
- Retains schema 5 and the existing authentication, authorization, approval and simulated execution rules. See `docs/MIGRATION.md` for recovery limits.

This local release has not been assigned a public repository, archive DOI or software license.
